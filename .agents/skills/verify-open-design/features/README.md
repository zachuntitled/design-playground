# Verification feature map

- [Projects](projects.md): create, list, reopen, and persist a local project through CLI and UI.
- [Settings](settings.md): reach execution settings from Home.
- [Artifacts and runs](artifacts.md): persist, render, and interact with an artifact through mocked and live-agent paths.
- [Live-agent acceptance](../references/live-agent.md): real generation, native conversation resume, and persistence across restart through UI and CLI.

Start with the feature affected by the change. Live-agent acceptance requires an available authenticated provider and records its exact model. This map does not establish cloud-account, packaged-app, or updater acceptance.
