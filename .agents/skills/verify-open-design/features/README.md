# Verification feature map

- [Projects](projects.md): create, list, reopen, and persist a local project through CLI and UI.
- [Settings](settings.md): reach execution settings from Home.
- [Artifacts and runs](artifacts.md): persist and serve an artifact, including a fake-agent run and event stream.

Start with the feature affected by the change. This seed map does not cover cloud authentication, real provider calls, packaging, or updater acceptance.
